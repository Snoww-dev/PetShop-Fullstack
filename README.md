# 🐶 PetShop App - Fullstack Project

Dự án ứng dụng mua sắm thú cưng, bao gồm App Mobile và Server Backend.

## 🌟 Công nghệ sử dụng
- **Mobile:** React Native (Expo)
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas

## 🚀 Cách cài đặt và chạy (Dành cho Dev)

### 1. Chuẩn bị
Clone dự án về máy:
git clone https://github.com/Tên-Nick-Của-Bạn/PetShop-Fullstack.git

### 2. Chạy Backend (Server)
cd Backend
npm install
node server.js

### 3. Chạy Frontend (App)
cd Frontend
npm install
npx expo start
